# PadhaiKaro release readiness

This folder converts the external review into release work that is verifiable in this repository.
It intentionally separates implemented controls from tasks that require an Apple account, a Play
Console account, production provider credentials, a hosted policy URL, or device testing.

- `REVIEW_IMPLEMENTATION.md` — item-by-item status and evidence.
- `PRIVACY_POLICY.md` and `TERMS_OF_USE.md` — publication-ready drafts that require the business
  contact and website URL to be filled before publication.
- `DATA_DELETION.md` — the user-accessible deletion/export process and operator SLA.
- `STORE_CHECKLIST.md` — human-owned Play/App Store submission work.
